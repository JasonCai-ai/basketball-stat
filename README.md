# 篮球比赛统计系统
这是一个使用 Vue 3 和 Vite 开发的篮球比赛统计系统，可以记录比赛数据、球员数据，并支持导出为 Excel 格式。

## 功能

- 球员管理：添加/移除球员，设置球员号码和球队
- 比赛控制：开始/暂停比赛，节次控制
- 数据记录：记录得分、犯规、换人等操作
- 数据统计：计算球员上场时间、得分、犯规和正负值
- 数据导出：支持导出原始数据库和 Excel 格式数据
- 数据导入：支持导入之前导出的数据库

## 数据存储

系统使用浏览器的 IndexedDB 作为本地数据库，所有数据都保存在本地，并支持导入导出功能。

## 使用说明
1. 首先添加两队球员，可以使用预设球员池或手动添加
2. 点击"开始比赛"按钮开始记录比赛数据
3. 使用替补区域上下场球员（每队最多5人同时在场）
4. 使用得分和犯规按钮记录相应数据
5. 比赛结束后可以导出数据进行分析

## 公司篮球赛

- 登录页选择“公司比赛”，或从日常比赛主页点击“公司比赛”。实时统计入口为 `#/company`，免登录历史入口为 `#/company/history`。
- 选择主队和客队，点击“载入对战名单 / 新建比赛”，再安排双方首发。名单来自《篮球赛报名信息汇总.xlsx》的“汇总报名”，只取“篮球队伍”，共 6 队、84 人，号码保留为字符串（含 0 号）。队名使用汇总页写法。
- 公司赛沿用得分、犯规、上下场、节次、上场时间、正负值、比分走势以及 JSON / Excel 导出。公司赛使用独立的 `CompanyBasketballStatsDB`，日常比赛继续使用原数据库。
- 比赛结束后点击“结束并归档”，记录进入公司赛历史比分。重复归档更新同一场；新建比赛会生成不同的比赛 ID，同日多场互不覆盖。清除当前比赛不会删除已归档记录。
- 本机归档存在当前浏览器，清理浏览器数据会丢失，建议从历史卡片导出 JSON。可用“导入公司赛 JSON”恢复，再归档。

### 公司赛公开历史目录

公司赛单独使用 `public/data/company/{年份}/`，与日常比赛的年度数据目录分开。

将导出的 `company_basketball_日期_比赛ID.json` 放入对应年份目录，并在该目录的 `matches.json` 数组中添加文件名，例如：

```json
["company_basketball_2026-10-20_比赛ID.json"]
```

部署后，所有设备可从公司赛历史入口查看公开记录；未发布前仅当前浏览器可见。本机与公开目录存在同一比赛 ID 时，优先显示本机修正版。报名源文件中的部门、尺码和对接人未导入网站。

测试比赛在 JSON 的 `game[0]` 中设置 `isTest: true`，历史卡片和详情会显示“测试赛”，导出备份也保留此标记。2026-10-20 爱康国兵对 AI 说稳了队（51:42）为功能测试赛。
