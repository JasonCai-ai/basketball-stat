复核后采用的调整

  1. 技术统计先统一尺度；得分兼顾场均与向联盟均值收缩的每分钟产出，保留此前时长减权。
  2. Elo 和胜率合并为一个战绩分量；设置尺度下限，避免小方差被强行放大。
  3. Elo 按历史当场参与时间更新，两队合计变动零和，分差修正封顶。预测只用此前比赛的平均时间。
  4. 近期采用日期衰减，只修正相对自身长期表现的变化；不重复奖励相同表现。
  5. 置信度同时受独立场次和分钟数约束；新人采用中性强度。
  6. 分段 RAPM 未加入本候选。比分模拟仍独立估算，不把它当作新战力模型的胜率。

复现与限制

npm run backtest:ratings -- --year=2026。完整参数、训练日期、预测、排名和源数据 SHA-256 见同目录 results.json。旧版聚合字段已逐一与基线源码核对，误差阈值 1e-9。

只有 39 场、34 人，多项信号相关、分队可能刻意平衡、历史导出名单可能包含临场变更；预测只在给定名单条件下成立。历史修正版用于回放，无法还原原比赛日的数据版本。回测不证明因果贡献，也不能补出投篮效率、助攻或防守技术统计。原始比赛 JSON 未改动。

旧版原预测只融合技术统计与 Elo，没有直接使用页面战力值；候选预测与候选战力共用潜在强度。因此这是产品计算流程对比，并不把两套页面战力值误称为赢球概率。分差标定偏保守，另列零分差基线。
